## 转语音 + 合成视频

```bash
# 1) 用任意 TTS 生成 voiceover.mp3（剪映/Edge 大声朗读/Azure TTS/火山引擎）
#    语速 1.0x，音色选“活泼女声/知性男声”均可，导出 mp3

# 2) 混流（视频 30s，音频自动对齐，短的补静音）
ffmpeg -i douyin-video/douyin_30s.mp4 -i voiceover.mp3 \
  -c:v copy -c:a aac -shortest -fflags +shortest \
  douyin-video/douyin_30s_with_voice.mp4

# 3) 如需加 BGM（抖音内配也可，本地混就再加一轨）
ffmpeg -i douyin_30s_with_voice.mp4 -i bgm.mp3 -filter_complex \
  "[0:a][1:a]amix=inputs=2:duration=shortest:dropout_transition=0,volume=1[a]" \
  -map 0:v -map "[a]" -c:v copy -c:a aac -shortest douyin_30s_final.mp4
```

`voiceover.txt` 为纯文本版（无标题无标点干扰），已同步生成。
